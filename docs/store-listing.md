## English (en)

**Short**

> A native Windows 11 Minesweeper built with WinUI 3 and the Windows App SDK. No ads, no account, no telemetry — opens in about 0.4 s.

**Description**

Fluent Sweeper is Minesweeper rebuilt as a real Windows 11 app: native WinUI 3 + Windows
App SDK, no Electron shell, no embedded browser. The window appears in about 0.4 s and
settles at 74 MB of private memory.

- **Feels like the OS** — Mica backdrop, a real title bar, real system controls. Clicks and scrolling track like Windows Settings: no stutter, no flashing, no popups.
- **Nothing in the way** — no ads, no account, no sign-in, no telemetry. The game never opens a network connection, so it plays offline.
- **Play details** — chord on a revealed number, first click always safe, crisp on 4K, and a reveal that ripples across the board on the compositor.
- **Records stay local** — best time per difficulty is stored on your PC only. Never uploaded, never synced.
- **Themes and languages** — light, dark or follow Windows; English, 简体中文, 日本語, Français, 한국어.

Needs Windows 10 version 2004 (19041) or later, x64. The Store package carries its own
runtime, so there is nothing else to install.
