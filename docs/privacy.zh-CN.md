# Fluent Sweeper 隐私政策

**生效日期：** 2026 年 11 月 10 日 · **适用范围：** Fluent Sweeper 1.3.x（微软商店包 `8D36016F.FluentSweeper`、侧载 MSIX 与便携 ZIP 版本）

Fluent Sweeper 是一个单机扫雷游戏。它没有账号系统、没有广告、没有统计分析 SDK，也没有自己的服务器。本文用直白的话说明：运行它时，数据到底发生了什么。

---

## 一、适用范围

本政策适用于通过微软商店、GitHub Releases（MSIX 与便携 ZIP）以及从源码自行构建的 Fluent Sweeper for Windows。以下内容不在本政策范围内：

- **微软商店的交易。** 商店处理的购买、下载、安装、退款与崩溃报告由微软按[《Microsoft 隐私声明》](https://www.microsoft.com/zh-cn/privacy/privacystatement)处理。我们只能看到聚合后的销量与评分报表。
- **GitHub。** 浏览仓库、下载 Release 或提交 issue 适用 [GitHub 隐私声明](https://docs.github.com/zh/site-policy/privacy-policies/github-privacy-statement)。
- **你的 Windows 设备。** Windows 自身（包括诊断数据设置）由微软负责。

## 二、一句话总结

| 问题 | 回答 |

MSIX 清单里只声明了一项能力 `runFullTrust`，这是桌面 WinUI 3 应用以普通桌面程序身份运行所必需的，不是数据访问权限。

## 三、设备上存了什么

应用会写一个很小的 JSON 文件；只有在出问题时，才会多写一个日志文件。

`%LOCALAPPDATA%\WinMine\settings.json`

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| `Theme` | `Dark` | 记住你选的是浅色、深色还是跟随 Windows |
| `Language` | `Japanese` | 记住界面语言 |
| `LastDifficulty` | `Expert` | 下次打开时回到上次的难度 |
| `CustomBoard` | `16 × 24，70 雷` | 记住自定义棋盘尺寸 |
| `BestTimes` | `初级：23` | 页脚显示的各难度最佳成绩 |
| `ShowBestTimeBadge` | `true` | 是否在棋盘下方显示这个最佳成绩 |
| `SoundEnabled` | `true` | 记住音效开关 |

`%LOCALAPPDATA%\WinMine\crash.log`

只有在出现未处理异常时才写入，目的是让崩溃可诊断、而不是静默消失。每条记录是「时间戳 + .NET 异常文本」——异常消息、堆栈跟踪，可能还包含程序集名与含有你的 Windows 用户名的文件路径。它是追加写入、不做轮转，**并且应用从不上传它**。

这两个文件都在你的用户配置目录内。除此之外没有别的写入：没有自己的注册表项、没有开机启动项、没有服务、没有驱动、没有计划任务。

## 四、网络行为

应用**不发起任何网络请求**。代码里没有 HTTP 客户端、没有 socket、没有更新检查、没有许可证校验、没有崩溃上报。

两件看起来像联网、但其实不是的事：

- **设置 → 关于 → “在 GitHub 上查看”**。点击时只是请求 Windows 用默认浏览器打开 `https://github.com/Churroser/winmine`。Fluent Sweeper 本身不传输任何内容；从这里开始你处在 GitHub 的条款之下。
- **微软商店**可能按自己的节奏下载并安装应用更新，这对任何商店应用都成立。这部分流量发生在 Windows 与微软之间。

## 五、这些数据为什么存在，以及怎么删

settings.json 唯一的作用是让下次打开时状态延续——同样的主题、同样的语言、同样的棋盘、同样的最佳成绩。它不用于识别你，其中任何一部分都不会被传输到别处。

控制权在你手上：

- **清除最佳成绩** —— 设置 → 数据 → 最佳成绩 → **清除**。
- **全部重置** —— 关闭应用，删除 `%LOCALAPPDATA%\WinMine` 文件夹。下次启动会以默认值重建。
- **商店安装版** —— 从 设置 → 应用 → 已安装的应用 卸载，包的数据会一并删除。
- **便携 ZIP 版** —— 删除你解压出来的目录；如果想连设置一起清掉，按上面的方法删除 `%LOCALAPPDATA%\WinMine`。

## 六、共享、出售、转移

没有。个人数据不离开你的设备，因此没有可供共享、出售、授权、出租或交给第三方的数据，也就不存在需要列出的处理者或次级处理者。没有数据经纪、没有广告标识符、没有跨应用追踪。

## 七、你主动发送的诊断信息

如果你在 GitHub 提交 issue 并粘贴了崩溃日志或描述缺陷，那是你自愿把内容交给 GitHub，它会成为公开 issue 的一部分。不想公开的内容请自行打码——应用本身已经做了更稳妥的选择：把日志留在你的磁盘上。

## 八、儿童

Fluent Sweeper 是一款适合所有年龄的解谜游戏，不收集任何人的个人数据，包括儿童。应用内没有聊天、没有用户生成内容，也没有任何途径能通过它与别的玩家联系。

## 九、安全

既然不传输任何数据，就没有需要保护的传输通道，也没有可被入侵的服务器。你下载到的内容完整性由 MSIX 签名（GitHub 版本用自签证书、商店版本用微软签发的证书）与每次发布一并提供的 SHA-256 校验和来保证。

## 十、政策变更

如果未来的版本需要收集任何东西，本文会在该版本发布**之前**更新，明确写出新增行为并更新生效日期。这个文件的修订历史在仓库里公开可查，任何改动都可被审计。
